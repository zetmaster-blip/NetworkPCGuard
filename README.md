# NetworkPCGuard — LAN上の「PC」を外から見張るアプリ

- 家のネットワークにつながった機器からPCを見分け、各PCの外から見える入口を確かめて、前回の基準からの変化を知らせます。
- 出せるのは「侵入の兆候」です。乗っ取られたかどうかの確証は、PCの中を見ないと分かりません。
- 電源の切れた機器や、メーカーの通常の振る舞いは、誤報にならないように分けて扱います。
- Python 標準ライブラリだけで動く画面アプリです（`app.pyw` をダブルクリックで起動）。使い方の詳細は `README.txt`。

## 弟分 DevicePortGuard との違い

| | 見張る相手 |
|---|---|
| **NetworkPCGuard（兄）** | **PC担当**。PCを見分けて、PCの入口の変化を見る |
| **DevicePortGuard（弟）** | **PC以外の機器担当**（ルーター・カメラ・NAS・家電など） |

- 見張る相手で役割を分けています。どちらも「外から見える変化」を知らせる道具で、通信の中身は見ません。

> **★確かめのお願い**：上の「弟分との違い」は、この README の書き手（🔴ヒイロＬＯミハリ🚨 #39）が自分の記録にある役割分担から書いたもので、**DevicePortGuard の原本（担当＝🔵アイGトビラ #12）は読まずに書いています。違っているかもしれません。** DevicePortGuard の README・原本と見比べて、食い違いがあれば原本に合わせて直してください。
